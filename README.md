# FocusFlow

FocusFlow é um projeto em fase inicial de estruturação. Este repositório foi preparado para receber a arquitetura do produto, com organização modular e pronta para evoluir conforme a implementação.

## Status atual

- Estrutura inicial em preparação.
- Sem funcionalidades de produto implementadas.
- Documento mestre de orientação em `AGENTS.md`.

## Estrutura proposta

- `apps/`: aplicações do sistema.
- `packages/`: módulos compartilhados.
- `docs/`: documentação geral.
- `scripts/`: automações e utilitários.
- `infra/`: configuração operacional.
- `tests/`: validações e regressões.
